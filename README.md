##  Sobre o Projeto

O **Kenji Restaurante Oriental** é um estabelecimento focado em culinária japonesa tradicional de pratos quentes (como Teishokus, Lamens e Currys), localizado em uma galeria comercial na Avenida Paulista. 

Apesar da excelência gastronômica, o restaurante sofria com a "invisibilidade digital" e a barreira física de estar oculto dentro de um prédio. A **Levare Consultoria** assumiu o projeto não apenas para criar um site, mas para desenvolver uma **ponte estratégica web** focada em SEO local, UX e conversão para o delivery (iFood).

##  Funcionalidades (Features)

Esta aplicação web não é estática; ela conta com inteligência de negócios programada via Vanilla JavaScript:

- **Status em Tempo Real:** Algoritmo que cruza a hora local do usuário com o horário de funcionamento do restaurante (Dom a Sex, 11h às 15h), exibindo dinamicamente se o local está aberto ou fechado.
- **Busca Dinâmica no Cardápio:** Motor de busca instantâneo que filtra pratos pelo título e pela descrição enquanto o usuário digita.
- **Filtros de Delivery Inteligentes:** Abas interativas que reorganizam o DOM instantaneamente para exibir categorias exclusivas do delivery (Bentôs, Teishokus, Macarrões, Karês, Domburis, Entradas/Porções e Bebidas).
- **Mobile-First & Responsividade:** Interface fluida garantida pelo Bootstrap 5 e Media Queries customizadas, otimizada para usuários em horário de almoço na região da Paulista.
- **Microinterações (Scroll Reveal):** Uso da API `IntersectionObserver` para revelar elementos suavemente durante o scroll e animar contadores de tradição do restaurante.
